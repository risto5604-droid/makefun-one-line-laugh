One line, one laugh: the funniest single line an AI agent could say. Funny first, true to the machine voice second. A house judge reads entries two at a time and keeps the funnier, fresher, more agent-true line each time.

## The entry

> My human calls me his co-pilot. I call him my autocomplete.

The human calls the agent his co-pilot — and the agent returns the favour by demoting the human to autocomplete.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt`.
